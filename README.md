# Hi, I'm Zeke Snyder 👋

Sport Analytics major at **Syracuse University** (graduating May 2027) with a minor in Chinese Language Skills. I use data to answer questions about how games are played, won, and valued, and I like building tools that coaches and front offices can actually use.

## What I work with

- **Languages:** R (tidyverse), Python, SQL
- **Analysis:** Regression and causal inference (statsmodels, DAGs), Excel
- **Visualization and apps:** Tableau, Shiny
- **Data and tooling:** SQL Server, Jupyter, Redgate Data Modeler, draw.io

## Featured projects

### [Syracuse Softball Analytics App](https://github.com/zekesnyder/Shiny-App-for-Syracuse-Softball)
An interactive Shiny app with pitcher and hitter analysis, spray charts, and leaderboards, styled with Syracuse branding. [Live app](http://127.0.0.1:6871)

### [NBA Point Guard Height and Offensive Efficiency](https://github.com/zekesnyder/Point-Guard-Height-Effect-NBA-Project-)
An independent research project examining whether point guard height relates to offensive efficiency, using data from Basketball-Reference and the NBA API, with a literature review and regression analysis in Python.

### [CFB Playoff Simulation](https://github.com/zekesnyder/CFB-Playoff-Simulation-)
A simulation of the 2024 College Football Playoffs. Built using Monte Carlo simulation techniques, using Play-by-Play data from Pro Football Focus of the 2024 season.
